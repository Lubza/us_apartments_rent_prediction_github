# US Apartment Rent Prediction

An end-to-end data science and machine learning project focused on analyzing
and predicting apartment rental prices across the United States.

## Project Overview

The goal of this project is to explore the main factors influencing apartment
rental prices and develop a machine learning model capable of predicting
monthly rent.

The project includes:

- Exploratory Data Analysis
- Distribution analysis
- Multivariate analysis
- Geographic analysis using latitude and longitude
- Missing value imputation
- Feature encoding
- Feature scaling
- Train/test split
- Baseline regression model
- Ensemble machine learning models
- Cross-validation
- Hyperparameter tuning with GridSearchCV
- Model comparison
- Interactive Streamlit dashboard

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Plotly
- Matplotlib
- Streamlit

## Dataset

The dataset contains approximately 10,000 apartment rental listings from
across the United States.

Features include property characteristics, location information,
amenities and rental price.

## Streamlit Application

The interactive dashboard will provide:

- Dataset overview
- Interactive exploratory data analysis
- Geographic rent analysis
- Model comparison
- Model explainability
- Apartment rent prediction
